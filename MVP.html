01. What is Path Traversal?

A filesystem access flaw allowing an attacker to read (or write) arbitrary files outside the web server's intended root directory by manipulating file path references.

02. Where is it Usually Found?

Static asset endpoints (?image=), PDF/invoice downloaders (?doc=), log viewers, and dynamic template or language selectors.

03. What Introduces the Flaw?

Concatenating untrusted user input directly into OS file-reading APIs without canonicalizing the resolved path and verifying it stays inside the base directory.
