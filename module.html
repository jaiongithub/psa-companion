Fundamentals & Normal Behavior

Core concepts, practical examples, and real-world analogies

01. What is Path Traversal?

A flaw where a website accepts filenames from users (like ?file=report.pdf) and opens them directly from disk. If the server doesn't restrict the path, an attacker can look outside the intended folder and read sensitive operating system files.

02. The Filing Cabinet Analogy

Imagine asking an office clerk for a file inside a cabinet labeled Public Brochures. If you ask for "../../Confidential/Payroll.xlsx", a careless clerk follows the instructions, steps out of the brochure cabinet, and hands you private payroll records.

03. Why Does It Happen?

Developers often join user input directly to a base folder path using string addition (base + input). Because the operating system interprets ../ as "step up to the parent directory", each pair climbs one directory higher toward the system root.
